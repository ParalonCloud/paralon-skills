# Security

## Reporting a vulnerability

Please email **contact@paraloncloud.com** with what you found and how to reproduce it. Do not
open a public issue for a vulnerability. We answer within two business days.

## What this plugin runs

The skills are instructions; the code that acts is the ParalonCloud MCP server,
`@paraloncloud/mcp`, which `plugins/paraloncloud/.mcp.json` pins. It runs on your machine with
your API key and is published from [ParalonCloud/paralon-mcp](https://github.com/ParalonCloud/paralon-mcp)
by GitHub Actions with npm provenance.
